Atlas A3 Assistant

Atlas is a personal AI assistant built as a university course project (CSCI 599, Agentic AI). It runs for a single owner and connects only to a dedicated test Google account containing synthetic data.

With the owner's consent it reads that account's Gmail and Google Calendar to produce briefings, summaries, meeting alerts and draft replies. Emails are sent only after the owner approves each one.

It is not offered to the public and does not accept new users.
