Privacy policy — Atlas A3 Assistant

Last updated: November 15, 2026

Who uses it

Atlas is a single-user course project. The only Google account it is authorized for is a dedicated test account holding synthetic data. It is not available to the public.

What Google data it accesses

  • Gmail (read-only) — to list and summarize messages and flag urgent or suspicious mail.
  • Gmail (compose) — to create drafts, and to send a draft only after the owner explicitly approves it.
  • Google Calendar events — to read the agenda, detect conflicts, suggest free time and create events on request.

How the data is used and stored

  • Data is used only to provide the assistant's features to the owner.
  • Message and event content may be processed by the AI models the owner configured (a cloud model provider and a model running on the owner's own computer) to generate replies. It is not used to train models by this app.
  • OAuth credentials are kept in the owner's private Google Cloud Secret Manager. Assistant state is kept in a private Cloud Storage bucket in the owner's project.
  • No data is sold, shared with advertisers or transferred to anyone else.

Google API Services User Data Policy

Atlas's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
